1. Introduction and Motivation¶

Mental health is influenced by many factors, including sleep habits, physical activity, academic pressure, and perceived stress. This makes mental health a strong topic for data science because it combines behavioral data, survey responses, and predictive modeling.

Rather than relying on a single dataset, this tutorial uses three related datasets to study the topic from complementary angles. The first dataset captures lifestyle and sleep behavior, the second focuses on stress and coping, and the third examines mental health outcomes in a student population. Together, they help build a broader story: stress is not just an isolated number, but part of a larger behavioral and social pattern.

The final modeling section focuses on the Sleep Health and Lifestyle data because it contains structured numeric and categorical features that are well suited for machine learning. The other two datasets strengthen the tutorial by providing additional context about coping and student well-being, which helps motivate why stress prediction is meaningful in the first place.

4. Model Building and Testing¶

4.1 Modeling Question¶

For the final tutorial, I focus on the following question:

Can lifestyle and sleep variables be used to predict whether a person belongs to a higher-stress group?

I use the Sleep Health and Lifestyle dataset for this model because it contains the cleanest set of predictors for this question. Instead of predicting the exact numeric stress level, I convert stress into a binary outcome called high_stress. This makes the task a classification problem, which is easier to interpret and evaluate with metrics such as accuracy, precision, recall, ROC AUC, and a confusion matrix.

4.2 Modeling Choice¶

I use a Random Forest Classifier because:

  • it can model nonlinear relationships,
  • it handles mixed numeric and categorical predictors well after preprocessing,
  • it provides feature importance scores,
  • it is a strong baseline model for tabular behavioral data.

I also use one-hot encoding for categorical variables and preserve numeric variables directly.

In [28]:
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import OneHotEncoder
from sklearn.metrics import classification_report, confusion_matrix, ConfusionMatrixDisplay, roc_auc_score
from sklearn.ensemble import RandomForestClassifier
import numpy as np

# Create binary target from the stress score.
stress_threshold= df['stress_level'].median()
df['high_stress']= (df['stress_level']>= stress_threshold).astype(int)

# Select predictors that are plausibly related to stress.
candidate_features= [
    'gender', 'age', 'occupation', 'sleep_duration', 'quality_of_sleep',
    'physical_activity_level', 'bmi_category', 'heart_rate', 'daily_steps',
    'sleep_disorder']

# Keep only columns that are actually present.
features =[col for col in candidate_features if col in df.columns]
model_df= df[features + ['high_stress']].dropna().copy()

X= model_df[features]
y = model_df['high_stress']

categorical_features= X.select_dtypes(include='object').columns.tolist()
numeric_features= [col for col in X.columns if col not in categorical_features]

preprocessor= ColumnTransformer(transformers=[('num', 'passthrough', numeric_features),('cat', OneHotEncoder(handle_unknown='ignore'), categorical_features)])

rf_pipeline = Pipeline(steps=[
    ('preprocessor', preprocessor),
    ('classifier', RandomForestClassifier(
        n_estimators=200,
        max_depth=8,
        min_samples_split=4,
        min_samples_leaf=2,
        random_state=42))])

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=42, stratify=y)

rf_pipeline.fit(X_train, y_train)

y_pred= rf_pipeline.predict(X_test)
y_prob= rf_pipeline.predict_proba(X_test)[:,1]

print("Stress threshold used for high_stress:",stress_threshold)
print("\nClassification Report:")
print(classification_report(y_test,y_pred))
print("ROC AUC:",roc_auc_score(y_test,y_prob))

cv_scores= cross_val_score(rf_pipeline, X, y, cv=5, scoring='accuracy')
print("Cross-validated accuracy scores:", cv_scores)
print("Mean CV accuracy:", np.mean(cv_scores))

5. Conclusions and Recommendations¶

This analysis set out to determine whether lifestyle and sleep variables can predict whether an individual belongs to a higher-stress group. The results suggest that these variables are highly predictive. The Random Forest model achieved strong performance, with high accuracy, near-perfect ROC AUC, and consistent cross-validation scores, indicating that the model captures a clear relationship between the input features and stress classification.

The confusion matrix further supports this, showing that the model correctly classified all lower-stress and higher-stress individuals in the test set.

Feature importance analysis provides insight into which factors drive these predictions. The most influential variables include heart_rate, quality_of_sleep, and sleep_duration, followed by age and physical_activity_level. This indicates that both physiological signals and daily habits play a key role in determining stress levels.

Overall, the model suggests that higher stress is strongly associated with poorer sleep quality, shorter sleep duration, and elevated heart rate. From a practical perspective, this highlights the importance of improving sleep habits and maintaining a healthy lifestyle as potential ways to reduce stress.

Future work could involve validating the model on a larger or more diverse dataset to ensure that these patterns generalize beyond this sample.

Examples
--------

    The simplest way to use nbconvert is

            > jupyter nbconvert mynotebook.ipynb --to html

            Options include ['asciidoc', 'custom', 'html', 'latex', 'markdown', 'notebook', 'pdf', 'python', 'qtpdf', 'qtpng', 'rst', 'script', 'slides', 'webpdf'].

            > jupyter nbconvert --to latex mynotebook.ipynb

            Both HTML and LaTeX support multiple output templates. LaTeX includes
            'base', 'article' and 'report'.  HTML includes 'basic', 'lab' and
            'classic'. You can specify the flavor of the format used.

            > jupyter nbconvert --to html --template lab mynotebook.ipynb

            You can also pipe the output to stdout, rather than a file

            > jupyter nbconvert mynotebook.ipynb --stdout

            PDF is generated via latex

            > jupyter nbconvert mynotebook.ipynb --to pdf

            You can get (and serve) a Reveal.js-powered slideshow

            > jupyter nbconvert myslides.ipynb --to slides --post serve

            Multiple notebooks can be given at the command line in a couple of
            different ways:

            > jupyter nbconvert notebook*.ipynb
            > jupyter nbconvert notebook1.ipynb notebook2.ipynb

            or you can specify the notebooks list in a config file, containing::

                c.NbConvertApp.notebooks = ["my_notebook.ipynb"]

            > jupyter nbconvert --config mycfg.py

To see all available configurables, use `--help-all`.
